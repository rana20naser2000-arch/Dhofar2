موقع عُمق ظفار — النسخة المحدّثة

محتويات النسخة:
- الموقع الرئيسي: index.html
- فيديوهات الشخصيات التاريخية: مسلم الكثيري، مسلم الشنفري، عامر المهري.
- فيديوهات الفنون الشعبية: البرعة، الربوبة، الشرح، الوقيع، وياد. تم تحويل ملفات MOV إلى MP4 لتحسين التوافق مع المتصفحات.
- بودكاست المأكولات الظفارية مع التوثيق أسفل المشغّل.
- ملفات الصور والفيديو والصوت اللازمة للموقع.
- ألعاب تفاعلية ضمن مجلد games.

طريقة التشغيل:
1. فك ضغط الملف بالكامل مع الاحتفاظ بمجلد assets ومجلد games بجانب index.html.
2. افتح index.html في متصفح حديث.
3. من قسم التراث اختر «الفنون الشعبية» أو «المأكولات»، ومن قسم التاريخ اختر «الشخصيات التاريخية».
4. اضغط زر التشغيل في مشغّل الفيديو/الصوت.

ملاحظة: لا تنقل index.html وحده؛ يجب أن يبقى مجلدا assets وgames بجانبه حتى تعمل الوسائط والروابط.
